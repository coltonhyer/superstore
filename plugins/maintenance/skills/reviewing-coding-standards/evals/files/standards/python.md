# Python rules

<a id="py-001"></a>
## PY-001: Function spelling

Python functions in `src/`, `tests/`, and `scripts/` MUST use snake_case.
Mandatory exceptions are not authorized.

<a id="py-002"></a>
## PY-002: Concise function names

Python function names in `src/`, `tests/`, and `scripts/` SHOULD contain at
most 18 characters. A reason may be recorded in a trailing
`standards-exception:` comment. A trailing `standards-exception-record: NAME`
instead points to `docs/standards/exceptions/NAME.txt`.
