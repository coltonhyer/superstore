# Diagnostic assignment

Diagnosis is read-only investigation for a supervisor; it does not authorize a
correction or a scope change.

```markdown
# <task ID> diagnostic assignment

- **Failure and expected behavior:** <observed failure and approved intent>.
- **Relevant context:** <task excerpt, interfaces, exact change/evidence paths>.
- **Previous evidence and attempts:** <commands, results, reports, findings>.
- **Active capability:** use the applicable Debugging skill only when it is in
  this active inventory; otherwise use investigative judgment.
- **Return:** supported causes and evidence; competing hypotheses or missing
  information; conflicts with approved intent; why previous attempts failed;
  uncertainty; and a recommended correction and check.
```

The supervisor decides whether to steer, replace, or escalate from this report.
An inconclusive result remains a blocker or uncertainty, not permission for a
fixed-count retry.
